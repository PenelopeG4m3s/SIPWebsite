STUDENT INNOVATION PROJECT

Project Description

My project is a pre-rendered free roam system using panoramas and depth maps. The project creates panoramas at the players position using data from surrounding points that have their own panorama and depth map.

Innovation Claim

The innovation of the project is that it captures the best aspects of the two traditional ways to do pre-rendered free roam. It captures the freedom of movement that projects which render out every position have, while also having the minimal file size that typical projects that use point to point movement have.
